Les traductions sont toujours sauvegardées automatiquement dans ce navigateur. Pour les centraliser, la plateforme peut déposer le fichier Excel directement dans le dépôt GitHub (dossier data/traductions/). Il faut pour cela un jeton d'accès personnel (fine-grained token) avec la permission Contents : Read and write sur ce dépôt.

Le jeton reste uniquement dans ce navigateur (localStorage). Ne l'utilisez pas sur un ordinateur partagé.
